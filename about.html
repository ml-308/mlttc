关于 MLTTC

马陆梦想家时刻表项目　·　最后更新：2026 年 11 月 1 日

MLTTC 是一个由学生与公共交通爱好者共同维护的公益时刻表项目。我们把散落在站牌、线路公告和车迷记录里的公交、班车时刻， 整理成一份可以搜索、可以纠错的电子时刻表，免费提供给每一个需要它的人。 这里没有广告位，没有付费会员，也没有会员墙后面的「完整时刻」。

一、我们是谁 二、我们做什么 三、数据从哪来 四、技术与原则 五、认识我们 六、参与共建 七、联系我们

一、我们是谁

MLTTC 由「马陆梦想家」与「LoFF_RtN」共同发起和维护。我们不是在运营一家公司：没有办公室，没有编辑部，也没有排班表—— 只有一群在课余和业余时间里改代码、对时刻、审数据的爱好者。

做这件事的理由很朴素：很多公交与班车线路的时刻信息只出现在站牌和纸质公告上，错过一班车，往往就要在风里多等二十分钟。 如果「几点几分有车」能被更快地查到，上学和通勤就能少一点不确定。

所以我们希望它保持简单：打开网页，输入城市和线路，看到时刻；想补充数据，注册后提交；发现错误，直接告诉我们。 注册只是为了让你能提交和修改自己的时刻表，查询功能对所有人开放。

目前的状态

站点仍处于 Beta 阶段，功能还在持续完善；时刻表数据由大家共同补充，覆盖范围也在一点点扩大。 如果某个页面在你的手机或浏览器上显示不正常，欢迎反馈——那对我们来说也是有用的数据。

三、数据从哪来

1. 大家提交，管理员审核

站内时刻表由用户自发提交：城市、线路、起点站、终点站、发车时刻、备注与执行时间等，提交后经管理员审核，再公开展示。 你提交的内容会作为公开的公益数据保留，也可以在「我的时刻表」中自行修改或删除。

2. 数据会变，我们尽量跟上

线路调整、临时改点、节假日方案……时刻表是最容易过期的信息之一。我们会持续跟进，但无法保证每一条都及时、完整、准确。 出行前请以公交运营企业、站牌等官方渠道发布的信息为准。

3. 发现错误怎么办

  • 在「我的时刻表」里修改自己提交的内容；
  • 登录后使用站内「BUG 反馈」，告诉我们哪条线路、哪个时刻有问题；
  • 或者直接通过下方的联系方式找我们。

时刻表数据仅供查询参考。因依赖本站信息造成的误车、绕路等损失，我们无法承担，但仍会尽力把数据做准。

四、技术与原则

站点的技术栈不复杂，原则也很简单。

我们坚持的几件事

  • 最小必要：只收集实现功能必需的信息，不要求真实姓名、手机号或精确地理位置；
  • 不投放广告、不做用户画像、不出售或出租个人信息；
  • 能静态就静态：能用一段 HTML 与 CSS 解决的问题，不额外加载框架和脚本；
  • 错误提示说人话：接口超限或网络异常时，尽量告诉你发生了什么、多少秒后可以再试。

站点是怎么跑起来的

  • 全站托管在 Cloudflare，接口运行于 Cloudflare Functions，数据存放于 D1（关系型数据库）与 KV（键值存储）；
  • 前端使用原生 HTML / CSS / JavaScript，配合 Web Components 组织页头、按钮、卡片等组件，没有引入前端框架；
  • 密码使用 PBKDF2-SHA256 加随机盐、迭代 100,000 次后哈希保存，数据库中不保存明文；
  • 登录凭证存放在带 HttpOnly、Secure、SameSite 属性的 Cookie 中，接口按 IP 做频率限制，超限返回 429。

更详细的说明见 《用户协议与隐私政策》。

如果你在站牌下拍到了一张新贴的时刻表，欢迎把它变成这里的一条数据。

六、参与共建

如果你想一起把这份时刻表做得更完整，有几种方式：

  • 提交时刻表：注册采用邀请制，需要与邮箱匹配的有效注册码；拿到账号后即可提交你熟悉的线路；
  • 纠错：发现时刻、站名或线路信息有误，用「修改时刻表」或「BUG 反馈」告诉我们；
  • 提建议：工具不好用、页面在某个设备上错位、想要某个新功能，都欢迎反馈；
  • 分享：把站点转给需要它的人，是最简单的支持。

请勿使用爬虫或脚本批量抓取、高频请求接口——这类流量会挤占正常查询，也会触发站点的频率限制。
